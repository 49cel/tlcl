# shell
- - -

- when we talk about cli or command line in general, we usually mean the **shell**, the **shell** is a program that takes keyboard commands and passes them to the operating system to carry out
- linux distros supply a shell program from the gnu project called bash (bourne again shell), but there are other shell programs too, for example: fish
- when using a gui, we need another program called a **terminal emulator** to interact with the shell. you can find it if you look through your desktop menu, kde uses `konsole`, i use `kitty` since it is better and i'm on hyprland
- all the terminal emulators pretty much do the same thing, they give you access to the shell
- you can use your up-arrow key to access your previous commands (usually retained throughout multiple sessions even after quitting), most distros remember the last 1000 commands by default
- even when we have no terminal emulator running, there are several terminal sessions running in the background. we can access these sessions called **virtual terminals** by pressing `ctrl + alt + f1-f6`
